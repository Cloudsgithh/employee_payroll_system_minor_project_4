# Employee Payroll System

## Project Overview

The **Employee Payroll System** is a console-based application developed using Python. It helps manage employee information, calculate salaries, generate payslips, search employee records, and save payroll data for future use.

This project demonstrates the practical application of Python programming concepts such as functions, dictionaries, conditional statements, loops, and file handling.

## Features

- **Add Employee:** Add employee details, including employee ID, name, department, basic salary, allowances, and deductions.
- **Calculate Salary:** Calculate gross salary and net salary automatically.
- **Generate Payslip:** Generate and save an individual employee payslip.
- **Search Employee:** Search for an employee using their employee ID.
- **Save Payroll Data:** Save employee records in a JSON file.
- **Display All Employees:** Display employee IDs, names, and net salaries.
- **Exit:** Save the payroll data before closing the program.

## Technologies Used

- **Programming Language:** Python
- **Modules:** `json`, `os`
- **Data Storage:** JSON file
- **Payslip Format:** Text file
